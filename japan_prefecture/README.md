# 都道府県の調べ物

## 基本的な調べ方

1. 自治体のキッズページで概要の概要をつかむ
   - 「〇〇県 キッズページ」で検索する
   - 例：[青森県キッズページ](https://www.pref.aomori.lg.jp/kids/)
2. 「〇〇県 概要」と調べて、県の公式広報資料を見る

- 都道府県内の地方区分があれば参照する
- 都道府県パズルをやる

##  その他

ファイル名のナンバリングはJISの**都道府県コード**に準拠する。
